# Number-Pop-up-game
Thats a number pop up game which you try to pop all side-by-side numbers.
Also program reads an input file which includes a number chart like given example in project.
If there isn't any side-by-side number left, then Game Overs but if it doesn't, you need to write one 
more input too to reload game-over checker.

Also you can write different charts or ask AI to create one, there is no limitation about hugeness of chart.
Finally, to start game, open terminal inside of directory which includes source code then write:
# python3 assignment3.py input.txt
